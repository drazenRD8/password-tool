# password-tool
Generate strong passwords and check their strength using Python
# Password Tool

Mali Python alat za generisanje jakih lozinki i proveru njihove jačine.

## Instalacija

pip install -r requirements.txt

## Pokretanje

python password_tool.py

## CLI upotreba

# Generiši lozinku od 16 karaktera
python password_tool.py --gen 16

# Proveri jačinu lozinke
python password_tool.py --check "MojaLozinka123!"

## Primer

</> PASSWORD TOOL (PRO)
1. Generiši novu lozinku
2. Provjeri jačinu postojeće lozinke

Izaberi opciju (1 ili 2): 1
Unesi dužinu lozinke (preporučeno 12+): 16

[+] Nova lozinka: aB3!xY9@kLmN2pQr
[i] Automatski kopirano u clipboard! (Ctrl+V)
